# Roadmap

## Phase 0 — Research & Architecture

- Define the Career domain and the Evolution Loop.
- Establish evidence, review, and skill-definition models.
- Identify a narrow validation scenario and success measures.

## Phase 1 — Career loop prototype

- Capture structured evidence from a small career workflow.
- Review evidence with provenance and confidence.
- Apply a traceable skill update and evaluate a later output.

## Phase 2 — Product validation

- Test the loop with more users, roles, and feedback types.
- Measure whether reviewed updates improve career outcomes or decision quality.
- Separate domain-specific behavior from emerging reusable patterns.

## Phase 3 — Extract proven abstractions

- Extract only patterns demonstrated across multiple Career workflows.
- Define framework boundaries from observed product needs.
- Validate any extracted framework with a second domain.
