# Evolution Loop

## Loop

1. A user takes a career action or receives an artifact.
2. The platform captures relevant evidence with its context and provenance.
3. A review evaluates the evidence; feedback is weighed rather than accepted as truth.
4. The reviewer accepts, rejects, defers, or scopes a potential skill update.
5. Approved updates create a versioned skill definition with a rationale and evaluation plan.
6. Later outputs use the approved skill version.
7. New outcomes are compared with the prior context to test whether the change helped.

## Guardrails

- Never conflate evidence capture with learning.
- Preserve contradictory evidence instead of overwriting it.
- Limit updates to the context supported by the evidence.
- Make the update reversible through versioning.
- Escalate ambiguous, high-impact, or weakly supported changes for human review.
